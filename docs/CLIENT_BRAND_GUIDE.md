# Sharnam · Brand guide for client sharing

**Rev 01 · Aug 2026** · For SPDC PMC, clients, and partner communications

---

## 1. Brand identity

| Element | Usage |
|---------|--------|
| **Mark** | शरणम् wordmark — use the official logo file only |
| **Logo file** | Provided as `logo.png` — do not recreate in Word/PPT |
| **Tagline** | *Project Management Consultants* (below logo on login) |
| **Legal name** | Sharnam Project Development Consultants (SPDC) |

**Do**

- Use the logo on white or light backgrounds, or on photo heroes with the frosted plate supplied in the portal
- Keep clear space around the mark (minimum height 56 px on screen)

**Do not**

- Write “Sharnam” in large text next to the logo — the logo already carries the name
- Stretch, recolour, or add boxes around the logo
- Use emoji or informal icons in client-facing PDFs

## 3. Typography

- **Headings:** clean sans-serif (display weight) — professional, not decorative  
- **Codes & IDs:** monospace — project codes (`SPDC-DEMO-01`), drawing refs (`A-04 R2`), RFI numbers  
- **Eyebrows:** small caps, wide letter-spacing — module names above page titles  

Example hierarchy on a report cover:

```
SHARNAM PMC · WEEKLY PROGRESS REPORT
SPDC-DEMO-01 · Arvind Worker Dormitory
Week ending 10 Aug 2026
```

## 4. Login & portal experience

The live portal login uses:

- Construction hero photography (site context)
- **Logo centred on hero** — transparent glass plate, no redundant text
- ISO certification strip (9001, 45001, 14001, 19650, 21502)
- Separate URL per user type (`/login/office`, `/login/site`, etc.)

This matches the **inside** product — same cards, same teal, same tone accents.

## 6. Photography & site evidence

Site attendance and field uploads store:

- **Selfie** (check-in / check-out)
- **GPS coordinates** with accuracy
- **Timestamp** in attendance register and audit log

Use real site photos in WPR/DPR — the portal tags evidence to date and project folder on SharePoint.

---

## 7. Voice & tone (client communications)

- **Factual, present tense** — “Wing B slab pour cleared” not “We successfully completed…”
- **Concrete numbers** — “12 open RFIs” not “several RFIs”
- **Separate concerns** — Quality NCR ≠ Safety NCR ≠ Information RFI (three different registers)
