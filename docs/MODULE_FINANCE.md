# Module — Finance (shell now, detail later)

**Status:** Module page + tools defined. Field-level workflows to be detailed with client in biweekly / post-build sessions.  
**Separate from:** Cost (MB, BBS, budget, cashflow, BOQ).

---

## Purpose

Track **commercial** documents on each project:

| Tool | What it tracks |
|------|----------------|
| Overview | Open invoices, POs, RA bills, COPs at a glance |
| Invoice tracking | Invoice no., party, amount, date, status, link to PO/RA |
| PO tracking | PO no., vendor, value, delivery vs billed |
| RA bill tracking | Running account bill cycles and certifications |
| COP tracking | Certificate of payment / payment certificate status |

## Relation to Cost

- **Cost** = quantities, MB, BBS, budget, cashflow curves.  
- **Finance** = invoices, POs, RA bills, COP.  
- COP / payment certificate tracking moves **out of Cost** into Finance.
